# Pretrained weights

The `omnimira` 0.2.0 package bundles the epoch-1000 fold-0 checkpoint, so users do not need a separate model download.

The exact filename, byte count and SHA256 are recorded in `manifest.json`. The checkpoint is licensed under CC BY-NC 4.0; see `MODEL_LICENSE.md` in the repository and the license notice bundled beside the checkpoint.
